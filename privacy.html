Privacy Policy

YouTube Autopilot · last updated 20 November 2026

YouTube Autopilot is a personal desktop program. Its owner uses it to publish videos to their own YouTube channel. It is not offered to the public.

What Google data the program uses

When the owner signs in with Google, the program asks for two YouTube permissions:

  • youtube.upload — to upload videos to the owner's channel;
  • youtube.force-ssl — to manage the owner's own channel: set video details and thumbnails, add videos to playlists, list the channel's videos and delete them when the owner asks.

The program does not read comments, subscribers, analytics, email or any other Google data.

Where data is stored

The sign-in key (OAuth token) is stored only on the owner's computer. Videos, titles and descriptions are created on the same computer and sent only to YouTube. The program has no server and no database. It does not collect, sell or share any data with third parties.

Google API Services

The program's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

How to remove access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the token file on the computer also removes access.
